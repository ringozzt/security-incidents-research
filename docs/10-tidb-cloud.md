# 10. PingCAP / TiDB Cloud 数据泄露

**来源：** [sorrycc 2026-10 梳理 §10](https://research.sorrycc.dev/@sorrycc/2026-10-security-incidents)  
**可信度：** 事件已确认（PingCAP 官方报告）；攻击方宣称规模未证实

## 概况

PingCAP 于 **10-19** 发布安全事件报告：攻击者使用**被盗服务账号凭据**访问部分内部系统，复制数据并取得源代码。凭据如何被盗，报告未说明。

## 时间线（据 PingCAP）

| 日期 | 事件 |
| --- | --- |
| 9-09 … 10-07 | 未授权访问期间 |
| 10-07 | 发现；开始停用受影响凭据 |
| 10-10 | 删除更多被盗凭据；移除跨项目过度权限；开额外云存储访问日志 |
| 10-12 … 10-13 | 外部机构报告 4 个漏洞 |
| 10-14 | 已识别被盗凭据全部作废；未授权路径封堵；4 漏洞修复并复测 |
| 10-19 | 发布报告 |

## 已确认被访问的数据

- TiDB Cloud 账号与产品使用：用户名、邮箱、组织/项目关联、SQL 编辑器文本与报错、部分组织/项目/集群标识。  
- 商务与账单：客户联系人、合同条款、订单、价格、付款条款、账单配置。  
- 源代码。  
- 一张导出表含**加密的** TiDB Cloud API Key；外部机构测试自有值无法直接当 API Key；其他可用凭据是否暴露仍未确定。

## 未受影响 / 未发现证据（PingCAP）

- 无证据表明存储在 TiDB 中的数据受影响。  
- 已审查生产系统中未发现攻击者执行命令或维持持久访问。  
- 生产日志中修补前是否有漏洞被利用仍在核查。

## 与攻击方说法的差异

| 说法方 | 内容 | 原文态度 |
| --- | --- | --- |
| FulcrumSec | 10.6TB、约 490 万文件；已公开约 200GB；近两月访问；多地区机构；明文 API Key | PingCAP 未回应 10.6TB；API Key 描述为加密；无证据表明被解密或使用 |
| Bitget | 存放在 TiDB Cloud 的数据被访问 | 称仅涉及公开交易日志 |
| 微信文章 | 「从代码仓库拿到云凭据」 | 官方报告中没有出现 |

## 处置（原文）

1. TiDB Cloud 用户轮换管理 API Key；审查组织成员与访问日志。  
2. 假设 SQL 编辑器中输入过的内容（含连接串、密钥）已泄露，相应轮换。  
3. 等待逐一影响通知；疑问可联系 security@pingcap.com。
