# 6. GitLab CVE-2026-110264

**来源：** [sorrycc 2026-10 梳理 §6](https://research.sorrycc.dev/@sorrycc/2026-10-security-incidents)  
**可信度：** 已确认（The Hacker News）

## 概况

**CVSS 10.0**，影响自 **7.0（2014）** 以来所有自建版本。漏洞来自同一研究者一个月内报告的**第四个**正则引擎问题。

## 关键事实

- 这是近期**第二个** CVSS 10.0：第一个是 10-12 修复的 CVE-2026-97229（仅影响 19.2+）；9-23 两个为 9.9 且需认证。「六周内第三个 10.0」说法不准确。
- **10-12 已升级的实例仍在本次影响范围内。**
- 修复版本：18.11.13 / 19.0.10 / 19.1.9 / 19.2.9 / 19.3.6 / 19.4.3 / 19.5.1。  
  其中 **19.3.6** 与 **19.4.3** 含数据库迁移，单节点升级会停机。

## 处置

无论 10-12 是否已升级，都需升到本次版本；涉及迁移的安排维护窗口。
